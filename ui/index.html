Инструкция по OCR переводу

1. В Foxhole, Discord или браузере нажмите [ALT+Q].
2. Экран затемнится, появится перекрестие (как Win+Shift+S).
3. Зажмите левую кнопку мыши и выделите рамкой нужный текст.
4. Отпустите мышь — перевод моментально выводится в оверлей.
5. Отмена выделения: клавиша [ESC].

Звуковые устройства Windows и интеграция

Назначение аудио-устройств
Выберите ваши физические микрофон, наушники и виртуальный кабель VB-Cable
💡 Настройка в Discord и Foxhole (Важно!)
В Discord (Настройки -> Голос и видео -> Устройство ввода / Микрофон):
• Выберите: CABLE Output (VB-Audio Virtual Cable)

В Foxhole (Settings -> Audio -> Microphone):
• Выберите: CABLE Output (VB-Audio Virtual Cable)

В Foxhole (Settings -> Video):
• Включите режим экрана: Borderless Windowed (Окно без рамок), чтобы Windows не прятала оверлей субтитров под полноэкранной игрой!
